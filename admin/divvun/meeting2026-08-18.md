## Necessary Innovations

- byrja arbeidet med å oppdatera Android- og iOS-appar pga nye krav eller nye OS frå Google og Apple
- feilrettingar og optimaliseringar i rust-versjonen av hfst, foma, vislcg3 og dermed i divvun-runtime; siste:
  > Key results:
  >
  >  - SMA: new automatic default is 4.76× faster and uses 62.4% less RAM than pre-fix Rust.
  >  - SME: 5.77× faster and 77.2% less RAM.
  >  - Versus C++, new Rust is 7.06× faster on SMA and 8.37× faster on SME (and 5.19x faster on KAL)
  >
  >  Why the improvement is so large:
  >
  >  - SMA previously materialized 75,989 × 49 = 3,723,461 redundant flag loops.
  >  - SME materialized 253,975 × 72 = 18,286,200.
  >  - The new overlay synthesizes those loops only when composition asks for them.
  >
  >  Correctness checks passed:
  >
  >  - All … outputs are byte-identical per language.
  >  - SMA: 99,017 states / 119,230 arcs.
  >  - SME: 352,310 states / 433,933 arcs.
  >  - Both are semantically equal to pre-fix Rust and C++.
