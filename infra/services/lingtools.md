# Lingtools

_Lingtools_ is the name for our [cgi-bin](cgi-bin.html) replacement. It
consists of a backend API written in Rust, as well as a frontend with an updated
look, written in SvelteKit.

It runs on the [gtweb](../servers/gtweb.html) server.

_Lingtools_ had the working name of _"webpipelines"_ before a better name was decided.
Any references to _webpipelines_ in code or documentation refers to _lingtools_.
